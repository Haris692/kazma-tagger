Exporter

XML de codage vidéo — le format que lit déjà la Feuille de Match (balises <instance>, comme SportsCode / Nacsport). À déposer dans l'onglet Données du rapport.

CSV — une ligne par action, colonnes prêtes pour pandas (pd.read_csv, séparateur virgule, UTF-8).

Sauvegarde complète — le JSON contient les actions, l'effectif, les réglages et les coups d'envoi. C'est lui qu'on recharge pour reprendre une session.

Repartir de zéro — efface les actions taguées, garde l'effectif et les réglages.
